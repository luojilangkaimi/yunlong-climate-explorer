# 云龙天池流域气候变化 · 交互系统

基于 CMIP6 五模式集合（MPI-ESM1-2-HR、MRI-ESM2-0、EC-Earth3、CanESM5、NorESM2-LM）与 CHELSA 气候态数据，
经 EQM 偏差校正、趋势保持恢复与 30m 地形细化，面向云南云龙天池流域
（约 7 km²，海拔 2557–3223 m）的气候变化预估与可视化。

## 页面入口

- `index.html` — 系统入口（跳转页）
- `climate-explorer/climate-explorer.html` — 交互探索器
  （2020–2090 逐年演化地图、双情景联动曲线、模式间不确定范围，仅显示流域范围；页面另附"现状速览"卡片，并排展示三张流域现状 2D 专题图：① 地形（30m DEM 晕渲，2557–3223 m）② 年均温（1981–2010，8.1–11.9 ℃，冷暖色标）③ 植被与河流水系（示意分类：湖泊·水体/河网·林木·草地/灌丛·高海拔偶发降雪区·示意））
- `climate-atlas/climate-atlas.html` — 结果图册
  （均值 / 变化 / 趋势 / 极端指数共 36 张流域图件，流域尺度 30m 精细化制图）

## 数据与方法

| 环节 | 说明 |
| --- | --- |
| 气候态 | CHELSA v2.1，1981–2010 逐月 |
| GCM 集合 | CMIP6 五模式（MPI-ESM1-2-HR、MRI-ESM2-0、EC-Earth3、CanESM5、NorESM2-LM，r1i1p1f1），中位数 + 模式间范围 |
| 未来情景 | CMIP6 SSP2-4.5、SSP5-8.5，2015–2100 |
| 偏差校正 | 非参数经验分位映射（EQM），逐格点逐月 |
| 变化信号 | 趋势保持口径：未来气候态 = 观测气候态 + GCM 变化信号 |
| 地形细化 | 30m Copernicus DEM，气温局部高程递减率法、降水双线性插值 |
| 流域边界 | 30m DEM 水文分析自动划定（约 6.98 km²） |

> 全部资源本地自包含（含 ECharts 与字体），可离线运行；部署于 GitHub Pages。
