# 云龙天池流域气候变化 · 交互系统

基于 CMIP6 双模式集合（MPI-ESM1-2-HR、MRI-ESM2-0）与 CHELSA 气候态数据，
经 EQM 偏差校正、趋势保持恢复与 30m 地形细化，面向云南云龙天池流域
（约 7 km²，海拔 2557–3223 m）的气候变化预估与可视化。

## 页面入口

- `index.html` — 系统入口（跳转页）
- `climate-explorer/climate-explorer.html` — 交互探索器
  （2020–2090 逐年演化地图、双情景联动曲线、模式间不确定范围）
- `climate-atlas/climate-atlas.html` — 结果图册
  （均值 / 变化 / 趋势 / 极端指数图件，含流域尺度 30m 精细化制图）

## 数据与方法

| 环节 | 说明 |
| --- | --- |
| 气候态 | CHELSA v2.1，1981–2010 逐月 |
| 未来情景 | CMIP6 SSP2-4.5、SSP5-8.5，2015–2100 |
| 偏差校正 | 非参数经验分位映射（EQM），逐格点逐月 |
| 变化信号 | 趋势保持口径：未来气候态 = 观测气候态 + GCM 变化信号 |
| 地形细化 | 30m Copernicus DEM，气温局部高程递减率法、降水双线性插值 |
| 流域边界 | 30m DEM 水文分析自动划定（约 7.30 km²） |

> 全部资源本地自包含（含 ECharts 与字体），可离线运行；部署于 GitHub Pages。
